# Moaz Medhat — Personal Developer Portfolio

Modern, high-performance personal developer portfolio showcasing technical systems, architecture credentials, and engineering projects.

Built with **React 19**, **Vite**, **Tailwind CSS**, and **GSAP**.

---

## ⚡ Features

- **Minimalist Aesthetic**: High-contrast, clean typography inspired by modern engineering portfolios.
- **Dark & Light Mode**: Persistent theme toggle with `localStorage` and OS color-scheme detection.
- **Interactive Project Sandboxes**: Real-time architectural simulations (Wafrly Causal AI Pipeline, Socket.IO seat reservation mutex, MOT transport compliance).
- **GSAP Motion & Interactions**:
  - Interactive 3D card tilt tracking cursor coordinates.
  - Animated stat counters.
  - Staggered scroll-triggered reveals with GSAP ScrollTrigger.
- **Mobile-First Responsive**: Fully responsive layout designed with Flexbox and CSS Grid.
- **Direct Resume Access**: Verified PDF resume download directly from the site.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, JavaScript (ES6+), HTML5, CSS3
- **Styling**: Tailwind CSS v3
- **Animations**: GSAP, GSAP ScrollTrigger
- **Icons**: Lucide React
- **Build Tool**: Vite v8

---

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Moazzmedhat/portflio.git
cd portflio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
